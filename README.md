## 1. Descripción del proyecto

Software FJ es un aplicativo desarrollada en Python el cual permite gestionar clientes, servicios y reservas mediante programación orientada a objetos.
Está hecho para administrar las operaciones de una empresa que ofrece reservas de salas, alquiler de equipos y asesorías especializadas.

## 2. Objetivo

Crear un sistema modular y funcional que permita registrar clientes, gestionar servicios, crear reservas y controlar su confirmación, cancelación y procesamiento.

## 3. Funcionalidades

- Registro y gestión de clientes.
- Registro y gestión de servicios.
- Creación de reservas.
- Confirmación y cancelación de reservas.
- Procesamiento de reservas y cálculo de costos.
- Validación de datos.
- Manejo de excepciones personalizadas.
- Registro de eventos y errores mediante archivos de log.

## 4. Tecnologías utilizadas

- Python.
- Tkinter para la interfaz gráfica.
- Programación orientada a objetos.
- GitHub para el control de versiones.

## 5. Organización de archivos

| Archivo        | Función |

| main.py        | Interfaz principal y ejecución |
| entidades.py   | Clase abstracta Entidad |
| clientes.py    | Gestión de clientes |
| servicios.py   | Clases de servicios |
| reservas.py    | Gestión de reservas |
| sistema.py     | Administración del sistema |
| excepciones.py | Excepciones personalizadas |
| registro.py    | Registro de eventos y errores |
| registro.log   | Archivo de registros |

## 6. Ejecución

Para ejecutar la aplicación, abrir la carpeta del proyecto en Visual Studio Code y ejecutar:

`python main.py`
